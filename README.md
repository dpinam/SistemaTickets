# Sistema de Tickets

Práctica 1 - Estructuras de Datos (SOFT-10)

Programa en Java para crear y resolver tickets desde la consola.

- Los tickets pendientes se guardan en una cola de prioridad.
- Los tickets resueltos se guardan en una lista enlazada simple.

## Cómo ejecutarlo

Abrir la carpeta en VS Code, abrir `src/Main.java` y dar clic en **Run**.
